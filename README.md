# 星詠遠征團：低語霧林（Astral Caravan）

Q 版像素風放置戰術 RPG（靈感來自《聖獸之王 Unicorn Overlord》戰術編排 × Roguelike 經驗入帳輪迴）。

## 遊戲特色
- **全自動橫向放置探索**：隊伍位於畫面中偏左，持續向尼布格靈汀近郊「低語霧林」深處推進，遭遇哥布林群、座狼騎兵與獸穴首領 **Barghest 巴吉斯特**。
- **前後排陣型與 2.5D 縱深站位**：近戰受前排阻擋，遠程與魔法可直擊後排，前後排詛咒與守護擋血各司其職。
- **聖獸風格戰術編排器**：支援雙條件 AND（`[限]` 強限制 vs. `[優先]` 軟優先）、死鎖偵測警告、MP 資源控管與一鍵最佳化。
- **固定三人班底與三系技能樹**：
  - **古斯比琪（Goodspeech）**：半精靈吟遊詩人（輔控／脆弱主坦／守護擋血）
  - **香卓莉爾（Chandrelle）**：精靈法師（高傷魔導輸出／鏡影術）
  - **海茵潔（Heintje）**：人類草藥師（草藥補血／長杖守護／前後排黑咒）
  - *預留第 4 席：旅途臨時 NPC 擴充位*
- **經驗入帳制 Roguelike**：野外獲得的經驗先帶在身上，主動回營地或擊敗 Boss 才正式入帳升級；全滅或陣亡撤退將損失一半未入帳經驗，但已習得的等級、技能樹、星塵祭壇與戰術配置永久保留。

## 如何用 GitHub Pages 免費上架試玩
1. 在 GitHub 建立一個新的 Repository（設為 Public）。
2. 將本資料夾內的 `index.html`、`README.md`、`.gitignore` 上傳至倉庫根目錄。
3. 前往倉庫的 **Settings → Pages**，在 **Branch** 選擇 `main`（`/ (root)`）並按 **Save**。
4. 等待約 1 分鐘，即可獲得公開試玩網址！
